# CLAUDE.md

Before starting any task in this repository:

1. Read `docs/PROJECT_CHARTER.md`. It is short and is the single source of truth.
2. Check the current milestone (top of the charter and Section 4). Work on that milestone. Do not build later milestones early unless the project lead asks.
3. Follow the safety rules (Section 5) and working rules (Section 6).
4. Treat the open questions (Section 7) as undecided. Ask; do not assume.
5. When a decision is made, add an entry to `docs/DECISION_LOG.md` and update the charter to match.

Environment: Python 3.11 in `.venv`. Test against the BrainFlow synthetic board (`--synthetic`) before using the Cyton.
